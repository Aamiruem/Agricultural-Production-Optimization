# farmer_queries.csv

A small **hand-written seed set** of farmer questions (108 rows, 7 intents) in
English and romanised Hindi, written for this project to demonstrate text
classification. It is not collected from real users. For production, train on
real query logs, e.g. the Kisan Call Centre dataset published on data.gov.in.

Intents: `pest_disease`, `fertilizer`, `irrigation`, `weather`, `market_price`,
`seeds_varieties`, `government_scheme`.
